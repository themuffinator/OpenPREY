openPREY

Open-source engine and game-code replacement for Prey (2006), built for modern Windows, Linux, and macOS systems while retaining compatibility with the original retail assets.

Repository · Releases · README · Build guide

What you need

openPREY does not include Prey assets. You must own and install a legitimate copy of Prey (2006), including its retail base/ data. Windows discovery supports registry and legacy CD-era install locations; a manual fs_basepath remains available.

Runtime layout

openPREY uses a single basepr/ overlay and one game_<arch> module for both single-player and multiplayer. Runtime packages contain the client, dedicated server, unified game module, and openPREY-owned pak0.pk4/pak1.pk4 content.

Development model

The engine is built with Meson. SDK-derived game code is maintained canonically in the companion OpenPrey-game repository and staged directly at configure time. Engine headers come from this repository; companion SDK duplicates are not compiled.

Always use windowed mode for automated validation: +set r_fullscreen 0.
