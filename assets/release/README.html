openPREY

Release package for the open-source Prey (2006) engine and game-code replacement.

Retail Prey assets are not included.

Requirements

  • A 64-bit system matching this package architecture.
  • A legitimate Prey (2006) installation with its original base/ data.
  • A compatible graphics driver and audio device.

Install and launch

  1. Keep the complete openPREY package together; do not copy retail PK4 files into basepr/.
  2. Run openPREY-client_<arch> (or the corresponding Windows executable/app bundle).
  3. If retail-data discovery fails, add +set fs_basepath "path/to/Prey" and point it at the installation root containing base/.

For Steam Deck packages, use openPREY-steamdeck. The dedicated server is openPREY-ded_<arch>.

A Linux AppImage, when provided, still requires your legitimate Prey (2006) assets. Mark it executable with chmod +x openprey-*.AppImage, launch it, and pass +set fs_basepath "path/to/Prey" if discovery does not find the retail install.

Package contents

  • openPREY-client_<arch> and openPREY-ded_<arch>
  • basepr/game_<arch>, the unified SP/MP game module
  • basepr/pak0.pk4, basepr/pak1.pk4, and basepr/mod.json
  • Platform launchers and runtime libraries where required
  • Optional Linux AppImage packages for x86_64 or aarch64

Support

Logs default to the configured save path under basepr/logs/openprey.log. Include that log and any generated crash report when filing an issue.
