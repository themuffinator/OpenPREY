## Upstream summary
Upstream OpenQ4 changed these paths heavily (~10.5k insertions) since fork abb9a688. SOUND: the channel volume pipeline was rewritten from dB accumulation to sanitized linear volumeScale multiplication inside idSoundChannel::UpdateVolume (2dd80ebe 'align attenuation, volume, pitch', 22c7c52f 'align OpenAL channel logic with retail'), with linear s_volume/s_musicVolume cvars applied there and listener AL_GAIN fixed at 1.0/0.0; soundShaderParms_t was frozen to the retail-Q4 ABI (attenuatedVolume added, f0b51cfa) and SSF flag bits renumbered (SSF_VO=BIT22, SSF_MUSIC=BIT23); SOUND_CLASS_MUSICAL=3 introduced; snd_shader.cpp gained a volumeDb token, decl text writer and Validate/Rebuild overrides (874a/874c decl-refs work); snd_world.cpp (+1136) got occlusion, doppler/velocity (c0d1ed2a), hardened demo/save parsing (ProcessDemoCommand now returns bool); AL_SoundHardware.cpp tripled in size with s_deviceName device selection, HRTF (b648aa1f), device monitoring/auto-recovery, silence fallback (a9601ceb) and EFX/voice hardening; IsEAXAvailable now exists natively. UI: DeviceContext.cpp was rewritten for TTF fonts + retail Q4 font parity (8632851a, 88793d2c, fe4440ec) — DrawText signatures gained adjust/style/chatWindow params and the glyph loop changed; Window.cpp (+1104) got child-pointer validation (58000531), IsSimple disabled (a2461f7e), and DrawBackground rewritten with WIN_MATCOVER/MATFIT/MATCANVASFILL (identical to openPREY's canvas-fill, same bit) plus splash/cinematic underlays and native overlays; idUserInterface::Redraw gained a useAspectCorrection parameter (tr_guisurf passes false for world GUIs), superseding openPREY's global bypass; transform-aware cursor bounds landed upstream verbatim (cc2d3309, same author) and were extended; RenderWindow.cpp was refactored (+549, 51a1051c) and already contains openPREY's viewport fix retargeted at engineWindowState (Vulkan Phase B5a 7f076176 moved window state out of glConfig); SliderWindow was reworked for controller/mousewheel navigation. Net effect: Prey-only features (subtitles, profanity censor, retail GUI def dialect, tab containers, spline text effect, dB cvar aliases, shader dialect) all survive as concepts but must be re-seated into rewritten host functions, while openPREY's infrastructure fixes (cursor bounds, canvas fill, RenderWindow viewport, world-GUI aspect bypass, device selection, IsEAXAvailable) are already upstream in equal or better form and should be dropped.

## Notes
Cross-subsystem dependencies to flag to other agents: (1) the subtitle system calls sessLocal.ShowSubtitle/HideSubtitle (src/framework/Session*) and reads g_subtitles defined in game code; (2) focus-mute callers (SetMuteForFocus) live in sys/framework; (3) s_musicvolume_dB and com_profanity cvars are defined outside src/sound (game/framework SysCvar); (4) UI_SetInWorldGuiRendering is called from the renderer (tr_guisurf) — upstream replaced it with Redraw(time,false), so the renderer-side call must be dropped during rebase; (5) idUserInterface::Redraw signature upstream is (time, useAspectCorrection) — all openPREY Redraw overrides/callers must adopt it. Notable trap: openPREY added fields to soundShaderParms_t (subIndex + 3 profanity fields) while upstream commit f0b51cfa deliberately restored the retail-Q4 ABI layout of that struct (adding attenuatedVolume) — for Prey the retail ABI target is PREY's gamex86, so the struct layout policy needs an explicit decision during rebase. Also note diverging soundclass numbering: upstream SOUND_CLASS_MUSICAL=3 vs Prey SC_MUSIC=4 (SOUND_MAX_CLASSES 4 vs 5). Several openPREY changes (matcanvasfill, cursor bounds, RenderWindow viewport) are byte-identical to upstream commits because the same maintainer cross-ported them — during rebase these will merge trivially or should be dropped in favor of the upstream (sometimes extended) versions.
